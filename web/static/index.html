Forward Pipeline (Compression)

  • Parsing: NL → X-bar syntax tree (standard linguistic constituents).
  • Canonicalization: X-bar → EngLISP S-expression (Verbs/Heads rotated to front).
  • Minimization: EngLISP → MinimaLIST (compresses double negatives, strips determiners).

Reverse Pipeline (Generation)

  • Expansion: MinimaLIST → EngLISP (restores default articles and structures).
  • Linguistic Mapping: EngLISP → X-bar (rebuilds grammatical tree skeletons).
  • Text Synthesis: X-bar → Natural Language (synthesizes words in correct syntax).
